Clean hand-off

The normalized activity dictionary is the central contract: dates, distance, pace, duration, HR, elevation, VO₂ max, calories and activity type. Everything downstream consumes that cleaned record.

Two output contracts

The Excel file preserves rows for offline analysis. The JSON payload adds metadata and precomputed monthly summaries so the dashboard can remain static and fast.

Where reuse stops

The browser intentionally has no Python runtime, so it cannot call the shared Python helpers. The small JS bucket mirror is the practical no-build trade-off.
